## FAQ

**Q: How is this free? What's the catch?**
No catch. Tarka AI is built by Credex, which sells discounted AI infrastructure credits. The audit is genuinely useful to you whether or not you ever buy credits from us. For teams with significant savings, we surface Credex as one option — you're never obligated to use it.

**Q: How current is the pricing data?**
Every price in the audit engine is verified against the vendor's official pricing page during submission week, with source URLs documented. We update pricing data weekly. If you spot an error, email us — accuracy is the whole point.

**Q: Is my data private?**
Your email and company name are never shown on the shareable audit URL — only tool names and savings numbers. We don't sell your data. The shareable link is designed so you can share your results publicly without exposing identifying information.

**Q: What tools does the audit cover?**
Cursor, GitHub Copilot, Claude (all plans including API), ChatGPT (all plans including API), Anthropic API direct, OpenAI API direct, Gemini, and Windsurf. We're adding more tools based on user requests — submit yours via the feedback link after your audit.

**Q: What if the audit says I'm already spending well?**
We'll tell you exactly that. "You're spending well" is a valid and honest audit result. We don't manufacture savings to generate leads. You can sign up to be notified when pricing changes or new tools create a savings opportunity for your stack.
